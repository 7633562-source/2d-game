# Движок игры (как всё устроено)

> Пользовательский документ. Полная карта — `DOCS.md`, правила `.cursor/rules/*.mdc`.

## Технологии
- Unity **6000.5.8f1** (редактор `F:\6000.5.8f1\Editor\Unity.exe`).
- 2D-физика на **200 Гц** (fixed timestep), solver 8/3, стабильные PD-гейны не трогать.
- Стиль: плоские процедурные фигуры (без текстур/спрайтов).

## Сцены
- **World** — основная сцена (существа, лес, костёр).
- **SampleScene** — стенд для headless-прогонов походки.

## Ключевые компоненты
- `StepPhaseDriver.cs` — fall-catch FSM ходьбы человека.
- `BalanceController.cs` — баланс (приводы колен/бедер/лодыжек).
- `Bird*.cs` — иерархия птиц и поведения.
- `Dog*.cs` — собака.
- `HeadlessTrial.cs` — headless-стенд (метрики походки).

## Сборка и проверка
- **Headless-стенд**: `Tools/run-trial.ps1 -Rebuild -Duration N -Label X` → метрики (torso, comTravelX, swingFootGrounded, циклы).
- **WebGL**: `Assets/Editor/HeadlessBuild.cs` (метод `BuildWebGL`) → `Build/WebGL`.
- **Публикация**: gh-pages → `https://7633562-source.github.io/2d-game/` (постоянная ссылка).

## Оркестрация (Hermes)
- Агенты Cursor CLI (профили physics/bird/dog/level) правят код.
- Grok-боты (CDP) — исследование и тесты.
- Автодеплой: супервизор ловит изменение кода → пересборка → gh-pages → тест ботом.

## Базовые правила (не нарушать)
- Не резать 200 Гц, не крутить стабильные PD-гейны ради FPS.
- Не коммитить без явного слова.
- Не добавлять текстуры/спрайты (только плоские фигуры).
